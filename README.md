# Student Academic Performance Prediction Using Machine Learning

## Project Overview

This project applies machine-learning techniques to analyse and predict student academic performance using academic and behavioural factors.

Two regression models were developed and compared:

- Linear Regression
- Random Forest Regression

The models were evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), and R-squared (R²).

## Objectives

- Explore and understand student-performance data
- Identify factors associated with final academic performance
- Prepare data for machine-learning analysis
- Train Linear Regression and Random Forest models
- Compare model performance
- Identify the better-performing model

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Key Variables

The analysis considered variables such as:

- Study hours
- Attendance
- Assignment scores
- Previous academic scores
- Participation
- Sleep hours
- Final grade

## Model Results

### Linear Regression

- MAE: 14.38
- R²: -35.37

### Random Forest Regression

- MAE: 2.74
- R²: 0.156

Random Forest performed better than Linear Regression on the selected dataset.

## Conclusion

The project demonstrates a complete introductory Data Science workflow, including data preparation, exploratory analysis, feature selection, model training, prediction, evaluation, and model comparison.

The Random Forest model produced lower prediction error than Linear Regression. Future improvements could include larger datasets, feature engineering, model tuning, and additional machine-learning algorithms.
